Result columns: `id,sub,hr,lasterr,ret,v0..v5,txt` (see header of `tools/probe_record.c`). `hr` `-` = API without HRESULT;
`lasterr` 0x5A5A5A5A = LastError untouched; -7777 = output not written; colours are 0xBBGGRR. `DrawThemeBackground`
rows (api `DrawThemeBackground`, 32x24 DIB prefilled 0x00FF00FF, plus an 8x8 raw dump per part): v0 = FNV-1a over
greyscale bytes, v1 = pixels changed, v2 = pixels with alpha != 0, v3 centre / v4 top-left / v5 bottom-right ARGB (signed
long), txt `grey=` 32 samples and `raw=` BGRA hex of the whole 8x8.

## Repeatability (two fresh boots, `diff` of the raw CSVs)

v6: 2 differing lines of 154123, v5: 2 of 32724 - both pairs are the same two rows:
* `RUN,time_utc` (timestamp)
* `P00006 SM93.R12` (GetSystemMetrics(93), an undocumented/reserved index: 592 vs 596): VOLATILE, ignore (not a theme value; do not turn it into a constant).
Environment reports differ only in `UptimeMs` and run time. No CRASH / HANG / OPENFAIL / NOAPI / NODIB line in any run (every class in the table opens or
returns a clean OpenTheme error row).

## Reading notes / surprises (also in the final report)

* HP_HEADERITEM: GetThemePartSize TS_TRUE = 6x24 for state 0 and every state, TS_MIN = 1x1, TS_DRAW(100x30) = 100x30,
  GetThemePosition(TMT_MINSIZE) = E_PROP_ID_UNSUPPORTED (0x80070490): the 24 is the TS_TRUE image height, not MINSIZE.
* Header HDM_LAYOUT cy (v6) = 24 for tm 13/15/16 fonts and 36 for a tmHeight 32 font; with HDS_FILTERBAR +21 (45/42/44).
  Unmanifested (v5): 17/19/20 and 35/39/41, GetWindowTheme NULL.
